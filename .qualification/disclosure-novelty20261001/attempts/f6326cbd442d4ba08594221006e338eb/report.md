An earlier API timestamp or Item2.02 tag does not verify the same fiscal period, disclosed components, public dissemination or an earlier tradable signal.
No observed candidate is not evidence that no earlier earnings disclosure exists.

Original failed10-Q captures remain in all requested denominators. Original manifest clocks are annotations, never silently requalified.

## Source limitations

- Current-member/classification cohort and current SEC submissions snapshots, not historically observed release vintages.
- Original capture history-page selection targeted2012–2025 filings;45-day lookback and7-day later boundary coverage are not assumed complete.
- Same CIK and earlier acceptance metadata are candidates only; original exhibit/header, fiscal-period and component linkage remain unverified.
- Unknown undiscovered releases are retained as unknown; original complete flag is scoped to the existing discovery procedure.
