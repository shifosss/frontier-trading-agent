# Five causal earnings inputs and source-only market preparation

`event_inputs.prepare_events(market, events, cohort, calendar)` preserves each original event and returns `feature_names` and `rows`. It appends event_id (`CIK:accession`), decision_timestamp, prior_price_index, entry_index, planned_label_end_index/session, model_inputs, model_input_status and model_input_reasons. The five inputs follow the unchanged frozen model specification. Every old event field, failed original and repeated same-session filing remains visible. Only a later account adapter may refuse an unresolved same-issuer decision collision; it must not silently overwrite it.

Market arrays have shape (official sessions, symbols): adjusted, vendor_quote_close and vendor_quote_volume. The explicit benchmark is SPY. The three price/activity inputs read only the preceding completed session and earlier observations. Original vendor close and volume stay paired in the same units; neither reconstructed nominal close nor later price availability substitutes for this calculation. Missing prior data remains unavailable. The original execution clock must match09:00ET after the availability floor, the official session close and the fifth subsequent close.

`extract_labels(market, rows)` is a separate outcome-reading call. For fit/calibration pass only those explicitly selected rows; test labels must not be accessed until test forecasts have been persisted. It requires the entry close and all five subsequent adjusted closes. Missing future entry/intermediate/exit marks never remove an otherwise eligible prediction event. Labels are keyed by event_id with status, targets `[return_5, downside_5]`, and unavailable reasons. Daily-close downside is not an intraday loss bound.

`prepare_market.py --definition PATH` extracts the fixed100-issuer cohort plus SPY from the previously saved broad cache; it does not compute events, labels, signals, models or account outcomes. It verifies the declared cache, cohort, calendar, capture index and raw sources, copies existing nominal close/adjusted close/ATR/settlement arrays, and separately maps original vendor quote close/volume. All requested members and source gaps remain. Its immutable definition binds dependencies and input identities before a unique source-only attempt; failures retain their evidence. Original quote parsing uses the same bytes that were hashed; all final input identities are checked before completion. No new download or alternative source is requested.

The source-only market output does not qualify complete corporate-action handling, historical universe membership, delisted coverage or as-of vendor vintages. Real financial qualification still requires terminal source completion and no active writer. All current tests are synthetic; the integrated20-account test is software validation, not a historical strategy result.
