# Original-event industry qualification interface

This isolated adapter reuses the unchanged S/Q parser. It has no network, prices, outcomes or models. The current100-issuer SEC source capture remains separate.

`header_industry.parse_header(raw, cik, accession)` inspects the exact original SGML header. `qualify_header(manifest, source_root, repo_root)` additionally requires one original-accession HTTP200 header source and verifies its raw hash. Outputs are `industry_status` (`qualified`, `excluded`, `unavailable`), `industry_sic` (four-character normalized numeric code or null), reasons, header source/hash and exact original byte spans. Well-identified co-filers cannot supply the target's SIC. Unknown/ambiguous FILER linkage is unavailable. Identical numeric duplicate fields agree; conflicting or malformed duplicates do not.

`enrich_filing` calls frozen Q.enrich_filing first, then appends industry evidence. `build_features(records, calendar)` calls frozen Q.build_features and adds `strategy_source_status` and `strategy_source_reasons`. Every pre-existing field remains untouched, including joint_feature_status, S, Q, u, selected, availability/execution clocks and history_accessions. A current event is strategy-source-qualified only when its original joint feature and original-header industry status are both qualified. The three causal price inputs remain a separate downstream requirement. Do not filter records by SIC before calling build_features: previous industry changes and unavailable older classifications deliberately do not rewrite the frozen S history.

`run_qualification.py --definition PATH` is the terminal-only collector. The root agent owns the actual declaration/freeze/run. No real corpus execution has occurred during implementation. A definition has schema1, source_root and calendar as repository-relative paths, expected_retained_original_records, and inputs mapping paths to SHA256. See the required list in run() for mandatory source/code identities. Terminal registry/completion inputs must be bound after capture ends; they are intentionally not guessed while the worker is live.

Before parsing it requires a terminal capture completion, no unresolved STOP, verified frozen source request/implementation/cohort, exact ordered100-member registry and matching registry request hash. It holds a read-only shared SQLite transaction on capture.lock.sqlite while reading sources; an active capture writer prevents collection, and the collector cannot mutate the source lock database. A separate lock in this directory prevents duplicate qualification jobs.

Terminal incomplete captures are allowed to produce explicit unavailable records. Missing manifests remain unavailable with their expected path and null file identity. Every discovered original is retained; every one of100 issuers receives a denominator record. Incomplete discovery has unknown undiscovered_original_count (null), never an invented zero or replacement issuer. Raw hash corruption is a fatal identity failure, not a new semantic gap. The collector rechecks all input hashes before finalizing unique attempt outputs.

Outputs under attempts/<unique-id>: records.json (full S/Q/SIC evidence); events.json (same full event denominator, bulky numeric-fact arrays omitted but exact source identities retained); issuer-status.json; source-inputs.json; summary.json; attempt.json. Failures retain failure.json and failed attempt status. No shared completed pointer, frozen request or active capture file is overwritten.

Two completed original headers were checked without financial-outcome processing: MCRB0000950170-21-000674→CIK0001609809/SIC2834 and CAG0000023217-13-000005→CIK0000023217/SIC2000. The direct nine-event synthetic comparison preserves every old event field and eight-prior history despite excluded/unavailable prior industry codes. The end-to-end collector check uses only temporary synthetic sources, retaining all100 issuers and one unavailable original.
