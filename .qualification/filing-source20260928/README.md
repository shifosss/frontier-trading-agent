# Bounded original SEC filing capture

Prepared for independent review and root launch only. No full acquisition, financial-feature calculation, return calculation or backtest has been run here. The only new public requests so far are the three predeclared identity metadata GETs; all returned200 and are cached.

`request.json` fixes AAPL/MSFT/F/T/HRL/BANF and **filing dates2012-01-01 through2025-12-31**, not fiscal-year labels. The rough expectation is252 original10-Qs, not an assumed completeness result. All discovered original accessions in that range are retained, including duplicate report periods. Discovered10-Q/A metadata remains visible, including amendments outside the interval; it never replaces an original. Each issuer has observed counts for all14 filing-date years and an explicit below-three coverage flag. Those counts do not prove fiscal-quarter completeness. A zero-original issuer remains unresolved and blocks a success status.

Current SEC metadata verified T/0000732717, HRL/0000048465 and BANF/0000760498; exact response identities are in `identity-verification.json`. Those are issuer locators, not historical ordinary-common-stock proof. T and BANF have additional current tickers; no array-position inference selects a security class. Historical original covers remain available for later class/CIK/ticker/exchange qualification. AAPL/MSFT/F use the previously saved original accession/cover evidence.

The runner discovers recent submissions and every declared history file overlapping the filing-date interval. Missing/malformed ranges, conflicting accession metadata or exhausted ceilings stay incomplete. Root metadata retains all history-file references, including unrequested out-of-range pages. Partial registry rows and all six requested issuers survive discovery failures. The complete registry is saved before per-accession documents are requested.

Each original receives its accession index, SGML header and complete primary document. `/ix?doc=` and `/ixviewer/doc/action?doc=` links normalize to that exact original Archives directory. The source representation is explicit: inline primary, or non-inline primary plus exactly one original EX-101.INS document. An ambiguous or absent original instance remains unresolved; no later accession, companyfacts value or extracted alternative silently replaces it. Financial tag/period/unit/context parsing is deliberately deferred. Older instance handling has a synthetic integration fixture; it has not yet been qualified on an acquired2012 instance.

The retained clock compares explicit-timezone submissions acceptance against index/header time in America/New_York and cross-checks filing dates, accession and CIK. Mismatches are reported separately from successful byte capture. A historical dissemination instant is never claimed. Archive content is a retrospective retrieval and may reflect later SEC corrections.

Bounds: at most8 overlapping history pages per issuer,60 original accessions per issuer/360total,1800 network starts for this capture,32MiB per response,4GiB of new raw cache payload, serial at most1request/second and30second timeout. The three prior identity probes have their own explicit3-request declaration. Completed HTTP/transport failures are preserved without automatic retries; an interrupted start with no durable result may be attempted once on a later resume, maximum2starts perURL.403/429 or a response-size breach records STOP and halts; resume does not bypass it. Other source failures remain visible. Raw source bytes are immutable/content-addressed and exact reused URL/hash sources avoid11 repeat requests. Reuse verifies hashes, including every saved filing source on resume; changed registry identities stop reuse.

`capture.py` uses the existing durable JSON writer and an independent SQLite exclusive lock, `capture.lock.sqlite`. It does not use or modify the historical-account lock, paper journals, broker endpoints or credentials. All requests are unauthenticated official SEC data/archive GETs with the prior honest project user-agent. Frozen source identities are checked before run; status and appended progress are operational outputs.

Offline validation:14 tests pass, covering the three real original indexes, Apple's API/index/header timezone agreement, both viewer-link forms, old instance selection, ambiguity, malformed/overlapping history ranges, cache/reuse corruption, changed registry rows, interrupted and failed-request resumption, access/byte stops, zero-issuer coverage and partial membership preservation. No production or prior source files were changed.
