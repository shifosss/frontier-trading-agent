# Retained research implementation and compact evidence

This directory is normally ignored for newly generated source captures/runtime artifacts. The October1 private publication explicitly includes project-authored research code/tests/reasoning, immutable compact definitions/results/audits and retained failed/pre-review snapshots. See [the handbook](../docs/project-handbook.md), [study summaries](../docs/handover/study-catalogue.md) and [publication allowlist](../docs/handover/publication-paths.txt).

These are multiple separately declared experiments, not one active test suite. Do not broadly discover every archived test or execute run_* files to recreate a result without restoring exact inputs and reading the definition. Large raw captures, trusted model payloads, row-level accounts, dependency runtimes and private broker journals are excluded and catalogued in the artifact inventory. No historical winner is promoted by publication.
