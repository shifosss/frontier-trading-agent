# Frontier Trading Agent — project handover, October 1, 2026

Start with [the project handbook](https://github.com/shifosss/frontier-trading-agent/blob/main/docs/project-handbook.md) and [the handover index](https://github.com/shifosss/frontier-trading-agent/blob/main/docs/handover/README.md).

The repository preserves the application, the original local Git history, 150 recorded owner/research/technical decisions, 28 study and diagnostic summaries, 137 indexed original documents, and compact research evidence. Failed hypotheses, unavailable data, execution assumptions and unfinished work remain visible. No strategy has been economically qualified for promotion.

The artifact inventory records 83,641 retained local research files totaling 31,764,902,437 bytes. Large raw source corpora, historical arrays, model binaries and row-level ledgers are omitted from ordinary Git. Their identities and recovery paths are recorded; the owner may keep them in separate controlled storage. Mutable paper journals and private broker identifiers are not published. A clone does not migrate an active paper operator.

## Earnings comparison evidence bundle

`earnings-comparison-20260929.zip` is the unchanged completed earnings-study archive, not the complete raw SEC corpus.

- Size: 155,043,133 bytes.
- SHA-256: `51a620b50b7462d04887d6317fc9b8a6b68ebafc8fb07e2e8386510c3f122c97`.
- ZIP entries: 192, comprising 191 payload members and one archive manifest.
- Includes frozen definitions, implementation, prepared events, saved models, account outputs, independent reviews and source discovery records. Original raw SEC filing payloads are not included.
- All 20 accounts completed; six gained and fourteen lost over the full test. None reached 5%, 10% or 15% in any reported calendar week. These are historical simulation results under declared conventions, not verified fills or a profitable trading recommendation.

The final Git content, original Git history and every archive member were checked for configured paper credentials, private broker identifiers and common token/private-key patterns. No matches were found. The two existing paper API credentials were stored separately as encrypted GitHub Actions repository secrets; they are not in this archive or Git history and cannot be downloaded from GitHub to configure another local machine.

Only the existing fixed Alpaca paper baseline is authorized for operation. This handover enables no live trading, option orders, new services or automatic strategy promotion.
