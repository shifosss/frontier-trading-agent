## Reproduce without searching the whole workspace

For each study, `study-catalogue.json` supplies exact definition, attempt/result/completion and checker-source paths, compatible runtime, omitted asset counts/bytes and safe first verification. Check hashes first using `Get-FileHash -Algorithm SHA256 -LiteralPath <path>`; this does not certify arithmetic or profitability. Then read the retained independent checker interface and restore its specified inputs. Do not use `run_*` as a verification command: it can acquire sources, refit models or execute another account study. The full latest earnings bundle is separately attached to the private handover release; its191payload files plus archive manifest do not include the raw SEC corpus.
